Implement the core next-valid-update executor against controlled snapshots first, then integrate the approved data adapter.

Milestone: **M1** · Priority: **P0** · Effort: **L** · Workstream: **backing**

## Acceptance criteria

- [ ] Apply the versioned cutoff and snapshot eligibility; record execution snapshot, units, cash movements, lots and immutable receipt event atomically.
- [ ] Execute buys and sells using deterministic precision/cost-basis rules, including partial exits.
- [ ] Unique settlement keys and durable batches make retries safe; a crash cannot debit without its matching position/event.
- [ ] Reject stale, disputed, missing or mismatched metrics and apply the agreed freeze/cancel policy.
- [ ] Test competing workers, replayed batch, old orders, insufficient/invalid snapshot and boundaries around the update cutoff.
