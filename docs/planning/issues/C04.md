Persist source-specific observations before any settlement can trust a number.

Milestone: **M1** · Priority: **P0** · Effort: **M** · Workstream: **data**

## Acceptance criteria

- [ ] Store artist/provider/metric, count, observed-at, fetched-at, source URL/evidence reference, parser version and validation result.
- [ ] Reject missing, nonnumeric, nonpositive and implausible/outlier readings into review; duplicate observations are idempotent.
- [ ] Keep accepted snapshots immutable and corrections linked; distinguish rolling monthly listeners from streams, followers and cross-platform counts.
- [ ] Test stale timestamps, duplicate fetches, provider mismatch and corrected observations.
