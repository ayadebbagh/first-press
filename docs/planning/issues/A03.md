Make the server authoritative for the initial 1,000 Credits, cash/reservations and immutable account events.

Milestone: **M1** · Priority: **P0** · Effort: **M** · Workstream: **backing**

## Acceptance criteria

- [ ] Grant 1,000 Credits once per eligible account with a unique ledger event; concurrent signup retries cannot duplicate it.
- [ ] Use integer centi-Credits and transactional balance/reservation invariants; reject negative/overflow/invalid amounts.
- [ ] Reconcile available Credits, reserved Credits and ledger totals through an admin diagnostic.
- [ ] No client-editable value or demo balance import can mint Credits; weekly grants remain disabled.
