The account anchor used an absolute app route in the generated file preview, so the browser attempted to open a local account file. Use the navigation provider for both file and server contexts and keep the account initial centered.

Milestone: **M0** · Priority: **P1** · Effort: **S** · Workstream: **identity**

## Acceptance criteria

- [ ] Account navigation stays inside the file preview and shows an honest preview-only account screen, including direct reload and a working return link.
- [ ] The running Next.js app still opens its actual account route, including keyboard activation.
- [ ] Center the account initial horizontally and vertically at desktop and narrow mobile widths.
- [ ] Regenerate the local preview and verify actual file and HTTP behavior in isolated desktop/mobile browser tests; preserve local demo state and keep server sign-in out of the file preview.
