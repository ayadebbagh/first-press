Existing native Brave testing used the file-preview React build because localhost binding was denied. Add an isolated Playwright browser and CI flow that never drives the founder's personal Brave window.

Milestone: **M0** · Priority: **P0** · Effort: **M** · Workstream: **foundation**

## Acceptance criteria

- [ ] Install pinned test tooling and browser binaries through supported package sources; keep tests/fixtures separate from real user storage.
- [ ] Test root redirect, direct app routes, invalid-route 404, hydration, search, buy/cancel/settle, receipt persistence and daily demo labeling against an HTTP Next.js production server.
- [ ] Cover narrow mobile and desktop widths, keyboard navigation, page/console errors and provide traces/screenshots on failure.
- [ ] Run in hosted CI if local binding remains blocked; record observed run URL/results, not only a configured workflow.

## Dependencies

No implementation dependency. Resolve the decision or spike on its own merits.
