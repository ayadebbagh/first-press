A backup is useful only when the portfolio and support history can be restored consistently.

Milestone: **M2** · Priority: **P0** · Effort: **M** · Workstream: **operations**

## Acceptance criteria

- [ ] Schedule encrypted off-host backups with selected retention, least-privilege access and failure visibility.
- [ ] Restore into an isolated environment and reconcile ledger/snapshots/receipts; record measured recovery time and maximum data-loss window.
- [ ] Document compatible app/schema rollback or forward-fix procedure and simulate a failed deployment.
- [ ] Verify secrets and private data never enter the public repository or CI artifacts.
