Public source and third-party artwork need distinct rights decisions. Source attribution alone is not permission to redistribute artist images.

Milestone: **M0** · Priority: **P0** · Effort: **S** · Workstream: **operations**

## Acceptance criteria

- [ ] Review bundled images/source metadata and remove, replace or obtain permission for assets without a suitable redistribution basis before wider release.
- [ ] Choose and record the owner's intended source-code license; leave code unlicensed until selected rather than inventing an MIT grant.
- [ ] Check public history for secrets, personal paths and generated tool output; use a separate asset notice where appropriate.
- [ ] Document embed attribution/provider requirements and ensure sample media does not imply artist endorsement.
