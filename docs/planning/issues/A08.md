Validate the accounting contract using integration tests against real PostgreSQL transactions, not only mocks of the demo engine.

Milestone: **M1** · Priority: **P0** · Effort: **M** · Workstream: **backing**

## Acceptance criteria

- [ ] Exercise concurrent buys/exits/cancel/settle, repeated signup, worker replay and transaction rollback.
- [ ] Reconcile all ledger, reservation and position invariants after generated sequences and partial failures.
- [ ] Cover per-user authorization, invalid units and duplicate idempotency keys with differing payloads.
- [ ] Add CI database setup, migration and isolation/cleanup; document the precision tolerances and expected vectors.
